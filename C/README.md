# C Practice

C practice programs covering core syntax, control flow, data structures, and file-based problem solving.

## Contents

- `Application program/` - menu-style and real-world style programs (airlines, billing, salary, geometry, games)
- `Array/` - search, min/max, reverse, counting, and element operations
- `CSV analyzer/` - CSV parsing and analyzer practice
- `CSV file analysis/` - analytics over class datasets from CSV files
- `Function/` - function-based math and utility exercises
- `If Else/`, `Loop and Conditional/`, `Switch/` - decision and control-flow practice
- `Matrix/` - matrix operations and tabular computations
- `Pointer/` - pointer-based statistics and aggregation tasks
- `Recursion/` - recursive function exercises
- `Statistics/` - univariate/bivariate and shift-based statistical routines
- `String/` - string indexing and string search practice

See the [repository root README](../README.md) for cross-language navigation.
