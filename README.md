# Practice-Codes

A compact collection of practice programs across multiple languages, focused on programming fundamentals, problem solving, OOP, and SQL query practice.

## Repository at a glance

| Folder | Focus | Details |
|---|---|---|
| [`C/`](./C/) | Core C programming | Arrays, strings, pointers, recursion, matrix work, and small applications |
| [`CPP/`](./CPP/) | C++ practice | STL, OOP, mathematical problems, and small games |
| [`Python/`](./Python/) | Python basics | Syntax practice, list exercises, and OOP basics |
| [`R/`](./R/) | R coursework and practice | Basics, visualization, statistical computing, and simulation |
| [`SQL/`](./SQL/) | SQL exercises | Functions, joins, views, transactions, indexing, and exam-style sets |

## Quick start

- **C**: `gcc file.c -o out && ./out`
- **C++**: `g++ file.cpp -o out && ./out`
- **Python**: `python3 file.py`
- **SQL (MySQL)**: `mysql -u <user> -p <db> < file.sql`
- **R**: Open `.R` files in R/RStudio and run per module or script.
