## Getting Started

### Prerequisites
- **C**: GCC or Clang compiler
- **C++**: G++ compiler or Visual Studio
- **Python**: Python 3.x interpreter
- **SQL**: MySQL Workbench (8 or higher)

### Compiling C Programs
```bash
gcc filename.c -o output
./output
```

### Compiling CPP Programs
```bash
g++ filename.c -o output
./output
```

### Running Python Scripts
```bash
python3 filename.py
```

### Running SQL Queries
```bash
mysql -u username -p database_name < filename.sql
```
