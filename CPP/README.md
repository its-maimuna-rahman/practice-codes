# CPP Practice

C++ practice programs focused on STL usage, OOP, algorithmic exercises, and small interactive programs.

## Contents

- `Application Programs/` - larger console-style application exercises
- `Map, Pair and Struct practice/` - associative containers and custom struct workflows
- `Mathematical Practice/` - number and array/matrix logic problems
- `Object Oriented Programming (OOP)/` - class-based modeling exercises
- `Small Games/` - guessing, rock-paper-scissors, and tic-tac-toe variants
- `String practice/` - anagrams, compression, searching, sorting, and text transforms
- `Vector practice/` - vector operations including merge, frequency, and menu tasks

See the [repository root README](../README.md) for cross-language navigation.
